Conventions

Every answer is JSON: { "data": … }, or { "error": { "type": … } } with a 4xx or 5xx status. database (503) means MongoDB can't be reached.

A player is a profile of an install of the game, sent as X-Halo-Key: 32 to 128 letters, digits, - or _. The server keeps only its SHA-256. Requests that read a leaderboard or a challenge take it too, to add the key's own place (me, mine).

CORS lets every origin in (nothing rides on cookies). A "CORS error" in a browser means the answer didn't come from this server.

Daily challenges change at midnight in the server's time zone. A challenge's runs are taken whenever it is played; the day's own top three, while it lasted, are kept on top of its leaderboard (dayTop).
